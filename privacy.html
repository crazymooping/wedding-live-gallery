นโยบายความเป็นส่วนตัว

ภาษาไทย · English · ปรับปรุงล่าสุด: พฤศจิกายน 2569 (November 2026)

Wedding Live Gallery เป็นเครื่องมือส่วนตัวของช่างภาพ ใช้แสดงรูปงานแต่งให้แขกดูแบบเรียลไทม์ ประกอบด้วย 2 ส่วน คือ (1) โปรแกรมอัปโหลดที่ทำงานบนคอมพิวเตอร์ของช่างภาพ และ (2) หน้าเว็บแกลเลอรีสาธารณะนี้

โปรแกรมอัปโหลด (ฝั่งช่างภาพ)

ขอสิทธิ์ Google Drive แบบ drive.file เพื่ออัปโหลดรูปและวิดีโอจากโฟลเดอร์ในคอมพิวเตอร์ของช่างภาพไปยังโฟลเดอร์ Google Drive ของช่างภาพเอง โปรแกรมไม่อ่าน แก้ไข หรือลบไฟล์อื่นในบัญชี และใช้งานโดยเจ้าของแอปเท่านั้น ไม่มีผู้ใช้รายอื่นล็อกอิน

หน้าเว็บแกลเลอรี (ฝั่งแขก)

หน้าเว็บแสดงรูปในโฟลเดอร์ Drive ที่แชร์ไว้ แขกไม่ต้องล็อกอิน และเราไม่เก็บชื่อ อีเมล หรือข้อมูลส่วนตัวของแขก รายการ "รูปที่ถูกใจ" เก็บไว้ในเบราว์เซอร์ของแขกเองเท่านั้น (localStorage) ไม่ถูกส่งมาที่เรา การแชร์หรือดาวน์โหลดรูปจะดึงไฟล์รูปมาที่เครื่องของแขกโดยตรง

ฟังก์ชัน "ค้นหาเลข NO." และ "หารูปของฉัน"

  • ค้นหาเลข NO. เป็นการกรองรูปตามเลขท้ายชื่อไฟล์ในเครื่องของแขก ไม่เก็บข้อมูลใดๆ
  • หารูปของฉัน (ค้นหาด้วยใบหน้า) เป็นฟังก์ชันที่แขกเลือกใช้เอง รูปเซลฟี่หรือรูปที่แขกเลือกถูกประมวลผลในเครื่องของแขกเท่านั้น ไม่ถูกอัปโหลดหรือบันทึกที่ใด ระบบแปลงใบหน้าเป็นชุดตัวเลข (ลายนิ้วมือใบหน้า) แล้วเทียบกับดัชนีใบหน้าของรูปในงานทันที
  • ดัชนีใบหน้าของรูปในงาน (ไฟล์ faces.json) สร้างโดยคอมพิวเตอร์ของช่างภาพตอนอัปรูป เก็บเป็นชุดตัวเลขของใบหน้าที่ตรวจพบในแต่ละรูป (ไม่ใช่ภาพใบหน้า) และเก็บไว้ในโฟลเดอร์ Drive เดียวกับรูป จึงผู้ที่มีลิงก์ของงานสามารถดาวน์โหลดไฟล์นี้ได้ ใช้เพื่อให้ฟังก์ชันค้นหาด้วยใบหน้าทำงานเท่านั้น ไม่ใช้เพื่อวัตถุประสงค์อื่น ไม่ขาย และไม่แบ่งปันให้บุคคลที่สาม
  • เบราว์เซอร์ของแขกอาจเก็บผลการสแกนใบหน้าชั่วคราวไว้ในเครื่องเพื่อให้ค้นหาครั้งต่อไปเร็วขึ้น (IndexedDB) และแขกลบได้โดยล้างข้อมูลเว็บไซต์ในเบราว์เซอร์
  • ระบบประมวลผลใบหน้าใช้ไลบรารีโอเพนซอร์ส face-api.js ซึ่งโหลดจาก jsDelivr CDN การโหลดนี้ไม่ส่งรูปของแขกไปที่ใด

การใช้ข้อมูลจาก Google API

ข้อมูลจากบัญชี Google ถูกใช้เพื่ออัปโหลดรูปงานไปยังโฟลเดอร์ Drive ของเจ้าของแอปเท่านั้น ไม่มีการขาย แบ่งปันให้บุคคลที่สาม ใช้โฆษณา หรือใช้ฝึกโมเดล AI การใช้ข้อมูลที่ได้รับจาก Google APIs เป็นไปตาม Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use

การเก็บรักษาและการลบ

รูปและดัชนีใบหน้าเก็บไว้ใน Google Drive ของช่างภาพ และลบได้ทุกเมื่อ เมื่องานสิ้นสุด ช่างภาพอาจปิดการแชร์โฟลเดอร์หรือลบรูปและไฟล์ faces.json โทเค็นการเข้าถึงเก็บไว้ในคอมพิวเตอร์ของช่างภาพเท่านั้น และเพิกถอนได้ที่ myaccount.google.com/permissions

การขอลบรูปของคุณ

หากคุณปรากฏในรูปและต้องการให้ลบรูปออกจากแกลเลอรีหรือลบข้อมูลใบหน้าของรูปนั้นออกจากดัชนี กรุณาติดต่อช่างภาพทางอีเมลด้านล่าง พร้อมระบุเลข NO. ของรูป เราจะดำเนินการโดยเร็ว

Privacy Policy

ภาษาไทย · English · Last updated: November 2026

Wedding Live Gallery is a small personal tool used by a photographer to show wedding photos to guests in real time. It has two parts: (1) an uploader that runs on the photographer's own computer and (2) this public gallery web page.

The uploader (photographer side)

It requests the Google Drive scope drive.file and uses it only to upload photos and videos from a folder on the photographer's computer into one Google Drive folder owned by the photographer. It does not read, change or delete any other files in the account, and only the app owner uses it; no other users sign in.

The gallery page (guest side)

The page displays the photos in that shared Drive folder. Guests do not sign in, and we do not collect names, emails or other personal information. A guest's "favorites" are stored only in that guest's own browser (localStorage) and are never sent to us. Sharing or downloading a photo fetches the image file directly to the guest's device.

"Search by NO." and "Find my photos"

  • Search by NO. filters photos by the number at the end of the file name, on the guest's device. No data is collected.
  • Find my photos (face search) is optional and started by the guest. The selfie or photo the guest picks is processed on the guest's device only and is never uploaded or stored anywhere. It is converted into a set of numbers (a face descriptor) and compared with the event's face index.
  • The event face index (faces.json) is created by the photographer's computer while photos are uploaded. It contains numeric face descriptors for faces detected in each photo (not face images) and is stored in the same Drive folder as the photos, so anyone who has the event link can download this file. It is used only to power face search, is not used for any other purpose, is not sold and is not shared with third parties.
  • A guest's browser may cache face-scan results locally (IndexedDB) to make later searches faster; guests can remove this by clearing the site's data in their browser.
  • Face processing uses the open-source library face-api.js, loaded from the jsDelivr CDN. Loading it does not send guests' photos anywhere.

Use of Google user data

Google user data is used solely to upload the event photos to the owner's Drive folder. It is not sold, shared with third parties, used for advertising, or used to train AI models. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Photos and the face index are stored in the photographer's Google Drive and can be deleted at any time. When the event is over, the photographer may stop sharing the folder or delete the photos and faces.json. Access tokens are kept only on the photographer's computer and can be revoked at myaccount.google.com/permissions.

Removal requests

If you appear in a photo and want it removed from the gallery, or want your face data removed from the index for that photo, please email the photographer below with the photo's NO. and it will be removed promptly.
